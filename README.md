# Okta-Bug-Bounty-Reconnaissance
Cybersecurity reconnaissance project on Okta domain using ethical hacking tools (Ping, Whois, Amass, DIRB) - Educational purpose only


📌 Project Overview

This project demonstrates ethical hacking reconnaissance techniques on **okta.com**, a leading Identity and Access Management (IAM) provider. All activities were conducted within the framework of Okta's official bug bounty program on HackerOne.

IMPORTANT:** This project is for **educational purposes only**. All reconnaissance was performed ethically using publicly available information and authorized tools.

🎯 Project Objectives

- Perform systematic reconnaissance on a real-world target domain
- Understand public information exposure and attack surface mapping
- Develop hands-on skills with industry-standard security tools
- Practice ethical hacking within bug bounty program boundaries
- Document findings professionally for security assessment reporting
-
